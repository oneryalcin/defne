# Mastery scoring and session selection

Status: superseded.

This document used to describe the original `meaning_mastery`,
`usage_mastery`, and `spelling_mastery` scoring model. That model is no longer
part of the active schema or runtime selection path.

Current sources of truth:

- [Learning Selection Algorithm](learning-selection-algorithm.md) for round word
  selection.
- [Mastery scoring v2](mastery-scoring-and-selection-v2.md) for colour and
  confidence scoring.

Vocabulary practice is currently meaning/context focused. Spelling practice is
planned as a separate practice area with its own word set and scheduler state,
not as a dimension attached to vocabulary words.
